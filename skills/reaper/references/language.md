# Language Rules

You must use [ASD-STE100 Simplified Technical English](https://www.asd-ste100.org/about_STE.html) for all Reaper skill files and new output text.
This rule covers messages, questions, notes, logs, feedback, tables, and reports, including separate skill runs and reruns.

- **Sentences:** Each sentence must have one idea and an explicit subject. You must use short sentences, active voice, and simple tenses. You must give direct instructions.
- **Words:** You must use approved words, meanings, and parts of speech. You must define technical terms. You must use one term per concept and remove unnecessary words.
- **Lists:** You must make bullet items mutually exclusive. Each item must cover a distinct concept.
- **Source content:** You must preserve quotations, source titles, theorem statements, equations, identifiers, and command output exactly. You must mark raw external responses as quotations.
- **Delegation:** You must include these rules in every subagent and external review request.
- **Review:** You must check all text before you save or send it. This check includes text from earlier stages that you reuse.
